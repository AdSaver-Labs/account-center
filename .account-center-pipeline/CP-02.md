## Internal issue

CP-01 is merged and the next open release-gate concerns the protected local API security contract. Existing routes have bearer, same-origin, and no-store coverage, but the production boundary needs a finite adversarial proof and hardened response header contract. This is an internal gate, not an external blocker.

## Bounded micro-tasks

1. Preserve the merged AC-06 owned delete receipt contract, Hermes/Dexter transport parity, and weekly-only inventory surfaces.
2. Add fixture-only adversarial request tests for bearer token exactness, same-origin mutations, body-size/format, and method/endpoint rejection.
3. Harden the fixed response-header contract without introducing CORS or caching exceptions.
4. Send only redacted, fixed error bodies for invalid/hostile input, and confirm no secret or identity echo.
5. Run targeted server and AC-06 fixture tests, full node/Hermes fixture suites, typecheck, browser/a11y QA, security QA, owned-helper trust pin, and diff check.
6. Review the bounded diff against the CP-02 acceptance, commit, push, and verify origin/main only if all gates pass.

## Acceptance evidence

- Every non-public API route demands the exact bearer token and no-store headers.
- State-changing routes require same-origin and strict JSON body guards.
- Adversarial input cannot echo tokens, emails, paths, or runtime diagnostics.
- Responses have fixed hardening headers and no cross-origin access exception.
- All evidence is fixture/mock only; the native delete helper is never executed.
